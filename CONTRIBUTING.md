# Contributing to Awesome Civil Engineering Teaching

Thanks for wanting to improve this list. To keep it trustworthy, every entry must meet the
same four rules that the existing ones follow.

## The four rules

1. **Free to access** — the useful content must be reachable without payment, login, or a
   time-limited trial. Commercial tools qualify only with a permanent free tier.
2. **Current** — the resource is maintained or recently reviewed, with no dead links or
   abandoned projects.
3. **Verifiable** — hosted by an identifiable organisation, project, or author. Sites of
   unclear origin, or sites redistributing other people's material without permission, are
   rejected on sight. Official standards texts (ASTM, BS EN, IS, BDS EN, BNBC) are never
   linked to unauthorised copies — link the issuing body instead.
4. **Your own words** — write a one-sentence description yourself. Do not copy or closely
   paraphrase the resource's own tagline or another awesome list's wording.

## How to suggest

**Issue:** open an issue titled `Suggestion: <resource name>` with the title, URL, the topic
group it belongs in, its license or terms of use, the last-updated date if visible, and your
own one-sentence description.

**Pull request:** add one line to the appropriate section of `README.md`, keeping the exact
format used by existing entries:

```markdown
- [Resource name](https://example.org) — one original sentence on what it offers teachers or
  students.
```

Sort entries alphabetically within a section. The weekly link-check workflow runs on every
pull request automatically and will flag any link that no longer responds.

## Review

Each suggestion is verified by opening the link, confirming the title and content, and editing
the wording for tone and length before merge. Contributors are credited in the commit history.
